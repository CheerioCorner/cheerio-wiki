# pi-plannotator-auto Project OKF Bundle

> Obsidian root Project Bundle pilot。這裡保存跨 session、跨本地環境的 project knowledge，不取代 package repository、原始碼或 package 內的 `docs/`。

## Boundaries

- **Package source of truth**：GitHub repository 與其原始碼。
- **Package OKF bundle**：repository 內的 `docs/`，隨 package 維護與發布。
- **Obsidian Project Bundle**：本目錄，保存跨 session 的 project context、project-local decisions 與 references。
- 三者不互相依賴，也不建立第二份 package source of truth。
