## 專案資料夾結構建議

每個專案資料夾至少包含：
```
project-name/
├── README.md        # 專案簡介、目標、進度
├── decisions.md     # 重要技術決策紀錄
├── issues.md        # 遇到的問題和解決方案
└── changelog.md     # 變更紀錄（可選）
```
