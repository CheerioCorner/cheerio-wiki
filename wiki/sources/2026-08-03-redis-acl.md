## 一句話

Redis ACL（Redis 6+）控制每個連線能執行哪些命令、存取哪些 key，實現最小權限原則。

## 重點摘要

### 核心概念

- **認證**：連線後需提供 username + password
- **預設行為**：新連線使用 `default` user，可存取所有命令和 key
- **向後相容**：`AUTH <password>` 仍可用（等同 `AUTH default <password>`）

### ACL 使用場景

| 場景 | 說明 |
|------|------|
| **安全性** | 限制不受信任的客戶端存取 |
| **操作安全** | 防止人為錯誤（如誤用 `FLUSHALL`） |
| **多租戶** | 管理式 Redis 中隔離客戶端權限 |

### ACL 語法

```bash
# 查看所有使用者
ACL LIST

# 輸出範例
1) "user default on nopass ~* &* +@all"
```

### ACL 規則一覽

| 類別 | 規則 | 說明 |
|------|------|------|
| **使用者** | `on` / `off` | 啟用/停用使用者 |
| **命令** | `+<cmd>` / `-<cmd>` | 允許/禁止特定命令 |
| **命令類別** | `+@<cat>` / `-@@<cat>` | 允許/禁止整個類別（@admin, @set 等） |
| **Key 模式** | `~<pattern>` | 允許存取的 key 模式（glob 格式） |
| **Key 權限** | `%R~<p>` / `%W~<p>` | 只讀/只寫 key 模式（Redis 7.0+） |
| **Pub/Sub** | `&<pattern>` | 允許的 channel 模式 |
| **密碼** | `><pwd>` / `<<pwd>` | 新增/移除密碼 |
| **Hash 密碼** | `#<hash>` / `!<hash>` | 用 SHA-256 hash 新增/移除密碼 |
| **無密碼** | `nopass` | 不需密碼（清除所有密碼） |
| **選擇器** | `(<rules>)` | 建立新選擇器（Redis 7.0+） |
| **重設** | `reset` | 重設使用者到初始狀態 |

### 範例

```bash
# 建立只讀使用者
ACL SETUSER readonly on >password123 ~* +@read +@safe

# 建立只能存取特定 key 的使用者
ACL SETUSER app-user on >secret ~app:* +@all

# 停用預設使用者
ACL SETUSER default off
```
