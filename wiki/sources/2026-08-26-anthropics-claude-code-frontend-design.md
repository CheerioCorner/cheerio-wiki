# anthropics/claude-code — frontend-design plugin

> Anthropic 官方隨 Claude Code 附帶的 frontend-design plugin，走 brainstorm→critique 的原則式流程而非硬性數字規格。

## 基本資訊

| 屬性 | 值 |
|------|-----|
| **維護者** | Anthropic（官方） |
| **範圍** | 單一 skill（plugins/frontend-design/ 下無其他子 skill） |
| **Companion** | Frontend Aesthetics Cookbook（anthropics/claude-cookbooks） |

## 結構

- **Frontmatter**：name: frontend-design
- **章節**：Ground it in the subject → Design principles → Process → Restraint and self-critique → More on writing in design

## 核心規則

- **具名 AI 設計反模式**：暖奶油底+高對比 serif+terracotta accent、深底+酸綠/朱紅、報紙式佈局
- **色彩**：4–6 個 named hex values
- **字型**：charismatic display face + complementary body face + utility face，每案專選
- **結構**：structural devices 必須 encode 真實內容，not decorate
- **動效**：orchestrated moment > scattered effects
- **剋制**：spend boldness in one place
- **流程**：compact token system → critique → build → critique again

與 taste-skill/hallmark 的數字硬規則不同，本 skill 不設固定 8px grid 或 HSL 公式，而是質性原則 + brainstorm→critique 工作流。
