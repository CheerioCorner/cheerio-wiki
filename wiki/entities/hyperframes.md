# hyperframes — HTML 轉影片的 Agent 工具

> 由 HeyGen 開發的開源工具，讓 AI Agent 透過撰寫 HTML 網頁來自動渲染成影片。

## 基本資訊

- **開發者**：HeyGen（https://github.com/heygen-com/hyperframes）
- **GitHub Stars**：41,244
- **授權**：開源
- **一句話**：寫 HTML，渲染成影片，專為 AI Agent 設計

## 核心用途

將 HTML 網頁內容自動轉換為影片。使用者（或 AI Agent）只需撰寫網頁程式碼，工具會自動將其渲染為動態影片輸出。

## 使用情境

1. **社群行銷短片批次生成**：同一個產品頁面 HTML，AI 自動產生多版本 15/30/60 秒短片，投放不同社群平台
2. **個人化年度數據回顧短影音**：用戶數據填入 HTML 模板，自動渲染成個人化回顧影片（類似 Spotify Wrapped 風格）
3. **AI Coding Agent 自動化原型影片演示**：Agent 開發完功能後，自動把功能頁面渲染成 demo 影片，附到 PR 或文件中
