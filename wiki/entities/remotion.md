# Remotion — 程式碼驅動的影片製作框架

> 用 React 程式碼製作影片的開源框架，資料驅動的程式化影片生成。

## 基本資訊

- **開發者**：Remotion Dev（https://github.com/remotion-dev/remotion / https://remotion.dev）
- **GitHub Stars**：56,520
- **授權**：開源
- **一句話**：用寫程式的方式做影片，最適合做數字、圖表這種動畫

## 核心用途

以 React 程式碼為核心的影片製作與渲染框架。與傳統視覺化剪輯軟體不同，使用者能透過程式碼邏輯精準定義時間軸、動態元件與畫面渲染流程。

## 使用情境

1. **金融報表數據故事短片**：每季財報數字自動轉為動態圖表動畫，生成可供投資人簡報用的數據故事影片
2. **個人化里程碑影片（Spotify Wrapped 風格）**：根據用戶年度數據（消費、學習、運動等）自動批次渲染個人化回顧影片
3. **社群賽事即時排行動畫**：比賽進行中，即時將分數/排名數據渲染為動態排行動畫，直播或賽後發布使用
