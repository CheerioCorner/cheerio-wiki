## 核心設計哲學

1. **協作式**：宣告設計系統 → 等使用者確認 → 才動工（非全自動）
2. **四個定位問題**：敘事角色 / 觀看距離 / 視覺溫度 / 容量檢查
3. **Anti-AI-cliché**：避免 purple→pink gradients、emoji-as-icons、Inter as display font
4. **動效克制**：CSS transition 優先（80%）→ React state/RAF → 自訂 timeline
