### 📝 學習筆記

#### 1. samplingParams：模型控制的入門

```
temperature = 0    → 穩定回答（適合 coding）
temperature = 1.5  → 創意回答（適合 writing）
top_p = 0.9        → 只從 90% 可能性中選
```

**原理**：模型每次生成一個 token 時，會根據這些參數決定如何從候選詞中選擇。

**可迁移到**：任何 LLM API（OpenAI、Anthropic、本地 Ollama）都用同樣的參數。

#### 2. thinking_token_budget：理解推理過程

```
問題：48 × 23 = ?

沒 thinking：直接回答 1104（可能算錯）
有 thinking：
  → 48 × 20 = 960
  → 48 × 3 = 144
  → 960 + 144 = 1104
  → 輸出：1104
```

**原理**：Chain-of-thought 讓模型先把推理過程寫出來，提高準確率。但思考需要 token，所以要「預算」。

**可迁移到**：所有支援 CoT 的模型都可調整這個平衡。

#### 3. Per-directory context：Agent 的分層設定

```
project/
├── AGENTS.md              # 全域設定
├── frontend/
│   └── AGENTS.override.md # 前端專屬設定（覆蓋全域）
└── backend/
    └── AGENTS.override.md # 後端專屬設定（覆蓋全域）
```

**原理**：不同目錄可以有不同的 agent 行為，不用全局改設定。

**可迁移到**：自己設計 agent 時，可以用類似的設定分層機制。
