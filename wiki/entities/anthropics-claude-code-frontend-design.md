> Anthropic 官方 frontend-design plugin——質性原則 + brainstorm→critique 工作流，不設固定數字規格。

## 基本資訊

| 屬性 | 值 |
|------|-----|
| **維護者** | Anthropic（官方） |
| **結構** | 單一 skill（plugins/frontend-design/ 下無其他子 skill） |
| **Companion** | Frontend Aesthetics Cookbook |

## 核心設計哲學

1. **質性原則**：不設 8px grid 或 HSL 公式，而是 storytelling-driven 設計
2. **具名反模式**：明確列出三種 AI 設計預設並要求避開
3. **流程**：brainstorm → token system → critique → build → critique again
4. **剋制**：spend boldness in one place

## 具名 AI 設計反模式

1. 暖奶油底 (#F4F1EA) + 高對比 serif + terracotta accent
2. 深底 + 單一 acid-green/vermilion accent
3. 報紙式佈局 + hairline rules + zero border-radius
