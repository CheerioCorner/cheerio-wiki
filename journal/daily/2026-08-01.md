## 💡 學到的

- Mimo-V2.5 會自動加入大量 template configs（可能是 GitHub repo template），需要人工檢查是否與專案相關。
- Checkpoint timestamps 應使用系統本地時間而非 UTC，避免跨日問題；也不應硬編碼特定時區。
- `Intl.DateTimeFormat` 雖然能格式化時區，但 `Date` 物件本身仍是 UTC，用 `getFullYear()`/`getMonth()`/`getDate()` 等方法才能取得系統本地時間。
- Pi 的系統 prompt 不會注入當前日期；模型自動顯示時間是 LLM 標準行為（training cutoff awareness），不在 extension 層面可修。
- Branch protection 要求 PR merge，直接 push master 會被拒絕。
- `git push --force-with-lease` 在 branch 被 delete 後重建時會 rejected，需要先確認 branch 狀態。
