## 💡 學到的

- Session shutdown hook 可以做 best-effort flush，但不能作為唯一保存機制；checkpoint 與下次啟動恢復是必要的。
- 任務完成不應由模型自然語言猜測，應透過明確 command 或確認流程。
- Package 核心不應寫死目前的 Obsidian 路徑，未來需要 TaskStore / JournalStore adapter。
- OKF 的入口文件與 AI 維運規則應該和 package 一起發布，避免實作與文件分離。
- 新 session 只要使用同一個 workspace，便能讀取 pending checkpoint 與 current Todo，接續 Phase 2 工作。
- 不可使用 UTC 日期直接建立日誌或 done 檔案；臺北跨日會造成前一天日期。
