## Cheer 的想法（2026-08-24）

Web MCP 這個 topic 大概半年前就已經提出過了，那時候認為普遍使用 AI 工具的人並不多，所以覺得效益很低；但隨著時間過去，現在越來越多人訂閱並付費使用 AI 相關工具。

它提出的概念不單單只是在現行網頁上提供一個 MCP 入口給瀏覽器掛載的 AI 使用，還包括現在的開發工具（像是 Claude、Cursor、VS Code 等）其實都有加入瀏覽器讓 AI 共同查看。

所以它不只可以提供現有網站系統給瀏覽器上的 AI（像是 Gemini、M365 或 Claude 等）直接控制、與你的網站互動，還包括在開發過程中，能有效協助本地 Agent 運作，讓開發者可以透過 Web UI 即時監控資料管道（data pipeline）的執行狀況、查看日誌與樣本資料等，藉此加速整個開發流程。

但個人認為它還是有很多資安議題，因為在網站上加了 Web MCP 就等於多了一個入口，駭客還是很有可能會利用這個機會。
