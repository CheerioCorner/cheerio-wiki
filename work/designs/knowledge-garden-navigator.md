## 一、Database Schema

### Properties

| 欄位 (Property) | 類型 | 選項 | 說明 |
|-----------------|------|------|------|
| **成長狀態** | Select | 🌱 種子期, 🌿 成長期, 🌳 成熟期 | 知識的成熟度 |
| **Notion 頁面** | URL | — | 種子/知識的名稱（主要連結） |
| **靈感/心得** | Text | — | 這顆種子帶來的啟發 |
| **研究專題** | URL | — | 所屬研究專題頁面（如有） |
| **Tags** | Multi-select | 🔬 研究, 🛠️ 實作, 📝 筆記, 💡 靈感, 📚 學習, 🎯 研究專題 | 知識分類 |
| **一句話** | Text | — | 30 字以內摘要（給 LLM 快速理解） |
| **Wiki GitHub** | URL | — | 對應的 wiki 頁面 GitHub 連結（導覽頁不顯示） |
| **種下日期** | Date | — | 首次建立時間 |
| **最後更新** | Date | — | 最近一次灌溉/更新 |

### 說明

- **有專案 vs 沒有專案**：透過「研究專題」欄位區分。有值 = 專案相關，空 = 獨立知識
- **Tags**：用 icon 前綴更直覺。Tags 與 wiki topics 的關係：Tags 是分類標籤，topics 是 wiki 內部的主題結構，兩者可對應但不強制
- **靈感/心得**：記錄每次接觸這顆種子時的啟發（放在第 3 欄，優先級高）
- **Wiki GitHub**：隱藏欄位，導覽頁面上不顯示，僅供系統同步用

## 二、Views 設計

### View 1：🗺️ 花園全景（預設）

- **Layout：** Gallery
- **Group by：** 成長狀態
- **Sort：** 最後更新 ↓（新→舊）
- **Card 預覽：** 顯示「一句話」摘要
- **用途：** 快速瀏覽花園全貌，一眼看出哪些在成長、哪些還是種子

### View 2：📋 清單視圖

- **Layout：** Table
- **顯示欄位：** Notion 頁面, 成長狀態, 研究專題, Tags, 一句話, 種下日期, 最後更新
- **Sort：** 成長狀態 ↑ → 最後更新 ↓
- **用途：** 完整清單，方便排序和篩選

### View 3：🏷️ 按 Tags

- **Layout：** Board
- **Group by：** Tags
- **Sort：** 成長狀態 ↑
- **用途：** 找特定類型的知識

### View 4：🔍 LLM 索引

- **Layout：** Table
- **顯示欄位：** Notion 頁面, 一句話, 成長狀態, Tags, 研究專題
- **Sort：** Notion 頁面 A→Z
- **用途：** 給 AI agent 用，快速理解花園內容，決定下一步操作

### View 5：📅 時間線

- **Layout：** Timeline
- **Date property：** 種下日期
- **Group by：** 研究專題
- **用途：** 追蹤知識沉澱時間，發現停滯太久的種子

### View 6：💡 靈感集

- **Layout：** Gallery
- **Filter：** 靈感/心得 is not empty
- **Sort：** 最後更新 ↓
- **Card 預覽：** 顯示「靈感/心得」
- **用途：** 快速瀏覽所有啟發，找靈感

## 三、導覽頁結構

### 導覽頁內容（markdown 草稿）

```markdown
# 🌱 知識花園導覽

> 這是 Cheerio 的知識沉澱空間。每顆種子都是值得深入的主題。

---

## 📖 如何使用

### 給人類
1. **找東西** → 用「花園全景」或「按 Tags」View 瀏覽
2. **深入了解** → 點進種子頁面，看「靈感/心得」和「成長計畫」
3. **灌溉知識** → 更新成長狀態、加入新觀察
4. **找靈感** → 用「靈感集」View 快速瀏覽所有啟發

### 給 AI Agent
1. **查詢花園** → 用「LLM 索引」View，快速掃描所有種子
2. **決定下一步** → 找 🌱 種子期的項目，或查看成長計畫
3. **新增種子** → 參考 Database 結構建立新頁面，填入所有欄位

---

[嵌入 Database — 預設 View: 花園全景]
```

## 四、與現有系統的整合

### 資料流

```
raw/ ──wiki ingest──► wiki/ ──種到花園──► Notion Database
 ▲                                        │
 │                                        │
 └───「花園裡那篇 X 要深入研究」──────────┘
```

### Manifest 同步

現有 `wiki/entities/knowledge-garden.md` 改為：
1. **主要資料來源** 改為 Notion Database
2. **Manifest** 降級為離線快取（Notion 異常時的 fallback）
3. **同步方向** 改為 Notion → Manifest（單向）
