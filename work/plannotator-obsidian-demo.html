💡 關鍵設計

Plannotator 的 Shared Event API 讓任何 Agent 都能透過標準化事件（plan-review, code-review, annotate）觸發標注 UI。 存檔時產生帶有 YAML frontmatter 的 Markdown，Obsidian 可直接讀取。

🔄 完整工作流：從對話到知識庫

plannotator://plan-review

1️⃣ AI 產生 Plan

Agent 根據需求自動生成執行計劃，包含步驟、依賴、風險評估。Plannotator 以視覺化 Checklist 呈現。

2️⃣ 人類瀏覽器標註

在 Plannotator UI 中，逐項 approve / deny / add comment。支援行級標註和整體決策。

3️⃣ Feedback 回傳 Agent

人類的標註透過 Shared Event API 回傳給 Agent，Agent 據此調整執行方案。

4️⃣ 存入 Obsidian

標註完成的 Plan 自動存入 Obsidian vault，帶有 YAML frontmatter（時間、來源、tags）。

5️⃣ 知識花園吸收

透過 plannotator-sync → raw/conversations → ingest，自動成為 wiki 的一部分。

💼 實際案例：我們的實驗

🧪 pi-plannotator-auto

基於 Shared Event API 開發的自訂 Extension

  • 🔧 open_annotate 工具 — AI 自動觸發標注 UI
  • ⌨️ /annotate 指令 — 手動標註最後訊息
  • 👁️ 視覺化 approve/deny + feedback
  • 📦 已發佈：github.com/CheerioCorner/pi-plannotator-auto

🔄 plannotator-sync skill

自動同步 Plannotator 產出到知識庫

# 完整流程 1. Plannotator 存檔到 plannotator/ 2. 說「sync」→ 搬到 raw/conversations/ 3. 說「ingest」→ 進入 wiki/ 4. 知識花園吸收 → Notion
全自動 已上線
📈 成果

從 2026-07 開始實驗，至今已累積： 25+ 個 source notes、 35+ 個 wiki 頁面、 6 顆知識花園種子。 所有與 AI 的深度討論都結構化沉澱，可追溯、可搜尋。

🚀 如何開始

⚡ 快速安裝

# 1. 安裝 Plannotator curl -fsSL https://plannotator.ai/install.sh | bash # 2. 安裝 Pi Extension pi install npm:@plannotator/pi-extension # 3. 開啟 Plan Mode /plannotator # 4. 設定 Obsidian 存檔 # Plannotator Settings → Enable Obsidian # 選擇 vault 與 destination folder

🔧 進階整合（選配）

# 安裝 pi-plannotator-auto pi install git:github.com/CheerioCorner/pi-plannotator-auto # 安裝 plannotator-sync skill # 已內建於 ~/.agents/skills/plannotator-sync/ # 使用流程 1. AI 產生 Plan → 自動觸發瀏覽器標註 2. 標註完成 → 自動存入 Obsidian 3. 說「sync」→ 自動同步到知識庫
⚠️ 注意事項

授權：Plannotator 採用 Apache 2.0 + MIT 雙授權，可自由 fork 與自定義開發。
相容性：支援 Pi、Claude Code、Copilot CLI、Codex、Gemini CLI 等 9+ 種 Agent。
環境需求：需要瀏覽器（用於標注 UI），支援 macOS / Linux / Windows。

🔮 未來展望

🤝 多人協作

利用 Shared Event API 實現跨裝置、跨團隊的 Plan 審閱。 標註同步到共享 vault，團隊成員可即時看到彼此的決策。
