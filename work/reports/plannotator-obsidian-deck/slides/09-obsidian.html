第二大腦

Obsidian：第二大腦與 Knowledge Graph

源自 Andrej Karpathy 的 LLM Wiki 想法，以及 Google 的 OKF （ Open Knowledge Framework ） 精神。

資料流

raw/
原始資料，唯讀
web / youtube / conversations
↓
wiki ingest
AI 整理、萃取、建立連結
↓
wiki/
concepts / entities / sources /
decisions / discussions

不需要向量資料庫：個人規模下， wiki + index 就夠用。 Markdown 是可長期保存、可被 AI 讀寫的知識格式。

核心 Skill
/wiki-ingest 將 raw/ 資料自動攝取、轉換並歸檔到 wiki/
/wiki-query 高精度關聯查詢，快速找到相關知識節點

🔍 Graph View 的四個價值

不是炫技的圖，而是系統性治理判斷工具：

品質控管 SKILL
/wiki-lint 語意連結校驗，自動偵測斷裂連結與孤兒頁
🔗

發現關聯

節點間雙向連結，顯示跨領域概念如何互相支撐

🕳️

知識缺口

揭露論述中應該存在、卻缺少的關鍵連結

📄

孤兒頁

識別沒有任何關聯連結的獨立筆記

🎯

決策樞紐

掌握連結數量最多、影響力最大的核心節點
