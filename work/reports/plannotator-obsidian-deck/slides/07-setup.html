安裝與落地

三步驟完成環境部署：自動安裝 → 手動微調 → 合規驗證，讓團隊快速上手。

推薦方法

讓 AI 自己動手裝

開啟 terminal 輸入以下指令：

npx skills@latest add
  https://github.com/EVACopilot/skills-itd-aas

選擇安裝Skill - plannotator-copilot-setup 和 wiki-init

然後在 Copilot 對話框（不是終端機）輸入：

/plannotator-copilot-setup

Plugin 加入 backnotprop/plannotator 後，安裝 plannotator-copilot@plannotator

然後在 Copilot 對話框（不是終端機）輸入：

/wiki-init

AI 會自動初始化 Obsidian 知識庫結構。

由 skills-itd-aas 統一治理與分發，跟企業 Agent Skill 共享機制是同一套。

接下來 3 件事仍要手動做

1
安裝 Copilot 外掛（貼上兩行指令，或 GUI 點 Install）
2
完整重新啟動 GitHub Copilot App
3
Shift+Tab 進入 Plan Mode 驗證

🔒 隱私與資安

  • 核心 Plan / Code / Annotation 全程在 localhost 執行
  • 公司政策只核准 Copilot 時，不要額外安裝其他 AI CLI
  • ⚠️ 敏感資料未經脫敏不得輸入公有雲 AI 模型

一句話重點：輕量化配置、合規守護，3 步驟即可完成團隊級別的環境部署。
