- **學到的事**：Notion Database 記錄和頁面 body content 是兩次不同的 API 呼叫，填完 Properties 不代表頁面有內容

- Agent（包含 Pi）的自我報告永遠只是「它以為自己做了什麼」，不是「它實際做了什麼」——要驗證就得自己讀 diff，不能只看報告清單
- 「已完成」的 commit 也可能夾帶未揭露的 side-effect 改動，尤其是批次腳本式的編輯（例如 index 全量重建）
- 這個 wiki repo 有背景自動 lint/commit/push 機制在跑，會在人不知情的狀況下把本地修改吃進它自己的 commit——這件事本身也值得另外調查清楚，確認它的觸發條件與行為邊界
