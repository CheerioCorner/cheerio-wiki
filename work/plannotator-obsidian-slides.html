Demo

完整工作流

  • 1️⃣
    AI 產生 Plan
    Agent 根據需求自動生成執行計劃，Plannotator 視覺化呈現
  • 2️⃣
    人類瀏覽器標註
    在 Plannotator UI 中逐項 approve / deny / comment
  • 3️⃣
    Feedback 回傳 Agent
    標註透過 Shared Event API 回傳，Agent 據此調整方案
  • 4️⃣
    存入 Obsidian
    自動存入 vault，帶有 YAML frontmatter + tags
  • 5️⃣
    知識花園吸收
    sync → raw/conversations → ingest → wiki

我們的實驗

🧪 pi-plannotator-auto

  • open_annotate 工具 — AI 自動觸發標注
  • /annotate 指令 — 手動標註
  • 視覺化 approve/deny + feedback
  • ✓ 已發佈到 GitHub

🔄 plannotator-sync

  • Plannotator 存檔到 plannotator/
  • sync → raw/conversations/
  • ingest → wiki/
  • ✓ 已上線運作
📈 成果：25+ source notes、35+ wiki 頁面、6 顆知識花園種子

如何開始

# 1. 安裝 Plannotator curl -fsSL https://plannotator.ai/install.sh | bash # 2. 安裝 Pi Extension pi install npm:@plannotator/pi-extension # 3. 開啟 Plan Mode /plannotator # 4. 設定 Obsidian 存檔 # Plannotator Settings → Enable Obsidian
